# Schedule Overlay 🗓️

An interactive, multi-layered calendar visualization and scheduling application built with **Streamlit** and **Python**. 

Schedule Overlay allows students, educators, and professionals to merge distinct schedules (e.g., college courses, fellowships, work shifts, or extracurriculars) into a unified, color-coded weekly grid, toggle seasonal design themes, manage events interactively, and export finalized schedules as formatted PDFs.

---

## 🌟 Key Features

* **Multi-Layer Architecture:** Create and manage distinct schedule tracks with dedicated, user-customizable color palettes using native hex color pickers.
* **Dynamic Seasonal Theming:** Switch instantly between custom-designed visual themes:
  * ❄️ **Winter** 
  * 🌸 **Spring** 
  * ☀️ **Summer**
  * 🍂 **Fall** 
* **Interactive Event Management (Full CRUD):**
  * Manually insert weekly events with flexible day selection and precise time ranges.
  * Live inline editing and deletion panel in the sidebar with immediate calendar re-rendering.
* **Snapshot & Preset Manager:** Save, name, load, and delete up to 10 distinct schedule presets directly within session memory.
* **PDF Export:** Generate and download a formatted, printable weekly calendar PDF matching your active configuration.
* **Configurable Grid Layout:** Toggle calendar views between Monday-start and Sunday-start formats.
